# 🎲 Guess The Number

A fun and interactive **Guess The Number** game built using **Python** and **Streamlit**.

## 📌 About the Project

This game generates a random number, and the player has to guess it. After each guess, the game provides hints to help the player find the correct number.

## ✨ Features

- 🎯 Random number generation
- 💡 Higher/Lower hints
- 🎮 Simple and interactive interface
- 🖼️ Attractive UI with background image
- ⚡ Built using Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit

## ▶️ Installation

1. Clone the repository:

```bash
git clone https://github.com/reevaa-28/guess-the-number.git
```

2. Go to the project folder:

```bash
cd guess-the-number
```

3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run guessnumber.py
```

## 🎮 How to Play

1. Enter a number.
2. Click the **Guess** button.
3. If your guess is too high or too low, you'll receive a hint.
4. Keep guessing until you find the correct number.
5. Enjoy the game!
